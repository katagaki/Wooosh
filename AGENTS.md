# Wooosh

Encrypted file sharing, local and peer to peer. Native apps for Android, iOS, macOS, and Windows over a shared Rust core. No accounts. The only server is Wooosh Rendezvous, a Cloudflare Worker that introduces devices across networks and stores nothing.

Specs in `Assets/Documentation/` are authoritative and must stay in sync with the code: [DESIGN.md](Assets/Documentation/DESIGN.md), [PROTOCOL.md](Assets/Documentation/PROTOCOL.md), [COPY_STYLE.md](Assets/Documentation/COPY_STYLE.md), [STATUS.md](Assets/Documentation/STATUS.md).

## Layout
| Path | What |
|---|---|
| `Core/` | Rust: `wooosh-core` (UniFFI) + `wooosh-cli`. Owns pairing, crypto, transfers. |
| `Apple/` | SwiftUI app (iOS + macOS), share extension, FFI framework. |
| `Android/` | Kotlin + Compose. |
| `Windows/` | WinUI 3 (C#). |
| `Worker/` | Rendezvous: Worker + Durable Objects, TypeScript. Never writes storage or logs (PROTOCOL.md §9.1). `src/roots/` is generated by `scripts/update-roots.sh`; never hand-edit. |
| `Apple/ci_scripts/` | Xcode Cloud hooks. Must stay beside `Wooosh.xcodeproj` and executable (`100755`). |
| `Assets/Documentation/` | All docs. No top-level `docs/`. |
| `Assets/Screenshots/` | All screenshots, never inside platform folders. |

Identifiers: `com.tsubuzaki.Wooosh` (Apple), `com.tsubuzaki.WoooshGo` (Android).

## Build
Rust is not on `PATH`: `export PATH="/opt/homebrew/opt/rustup/bin:$PATH"`.

```
cargo test --lib --release && cargo test --release --test integration -- --test-threads=1
xcodebuild build -project Wooosh.xcodeproj -scheme Wooosh -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew assembleDebug
cd Worker && npm test        # npm run dev (cf dev) serves the Worker on :8787; deploy with cf, never Wrangler
```
Internet path end to end (with `npm run dev` running): `WOOOSH_TEST_RENDEZVOUS=http://127.0.0.1:8787 cargo test --release --test integration -- --ignored --test-threads=1 internet_ticket_via_local_worker`.

After changing `Core/src`:
- Run `Core/build-bindings.sh`. Apple picks it up in place; **Android does not**: re-copy the Kotlin bindings and `jniLibs` into `Android/app/src/main/`.
- Build both Apple destinations. The script only builds a static library, so link failures show up only in the app. Frameworks a Rust dependency needs go in `OTHER_LDFLAGS` on `WoooshCoreFFI` by hand.

## Rules

**Project files**
- `Apple/Wooosh.xcodeproj` is hand-edited and authoritative. Never run `xcodegen` or recreate `project.yml`.
- Never change `DEVELOPMENT_TEAM` (`YYM4Z6MU8F`).

**Git**
- Commit messages are a single line.
- Always commit after a major change.

**Platform**
- iOS on the App Store, Android on Google Play, macOS notarized Developer ID, Windows sideloaded MSIX.
- Minimum OS 27 on iOS and macOS. Liquid Glass unconditionally, no `#available` fallbacks.
- Native UI only: SwiftUI, Compose, WinUI 3. Accent follows the system (no `AccentColor` asset; Material You).

**Device list (non-negotiable)**
- Ordered by first discovery. Append-only, never re-sorted.
- Peers that stop advertising grey out in place, disabled, never removed.
- Stale threshold is 10 s (scanning every 2 s). Do not change it.

**Design**
- macOS is first-class, not a port: system toolbar, `Settings { }` scene, Mac-sized controls.
- iOS sheet buttons are full-width, ≥44pt (aim ~50pt).
- iOS bare Done/Cancel use `Button(role: .confirm)` / `Button(role: .cancel)` with no label.
- Device icons come from the `dt` enum (PROTOCOL.md §3.1). Non-Apple phones use `smartphone`. Unknown values get a neutral glyph.

**Behaviour**
- Received files route automatically: iOS media to Photos, documents to Files; elsewhere to Downloads. Hash-verified before leaving staging.
- Preserve original filenames. Never rename or transcode.
- Keep the screen awake during transfers on mobile.
- Share extension or share target on every platform.
- Fast for 500 kB and 4 GB files, and any file count.

**Security**
- Never ask a user to compare something the other device does not display.
- Security confirmations need a deliberate press, never a default/Return action.
- A changed pinned key hard-fails. Never silently re-pin.
- The rendezvous never sees identity keys or ticket tokens and stores nothing. Attestation is abuse control, not a substitute for pinning.
- Shells never reimplement core crypto. Use `fingerprint_phrase_for` / `device_id_for`.
- Fingerprint phrases are never translated.

**Copy** (see COPY_STYLE.md)
- Professional, concise, no jargon.
- Say "Wooosh", never "this app" or "the app".
- No em-dashes.
- Title Case for buttons, headers, and titles, in English only.
- Localize everything: en, ja, ko, zh-Hans, zh-Hant, de, es, fr, it, nl, pt-BR, pl, ru, sv. No hardcoded display strings.

**Working style**
- Verify by building and testing. Report honestly what was and was not verified.
- Comments explain constraints the code cannot show. No narration.
- Keep all platforms at feature and settings parity, one term per concept.
